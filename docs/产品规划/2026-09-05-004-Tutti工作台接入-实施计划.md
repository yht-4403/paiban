## 实施边界与设计

首批主链路：A 问 B 的 Agent → 共享资料代答 → 显式找本人 → B 回复并确认 → 生成双方可追溯的任务。

前端采用 React / TypeScript / Tailwind 4，直接使用 Tutti 公共组件与语义样式；精确版本写入锁文件。页面由项目导航、成员与会话侧栏、主会话、上下文和待拍板区域组成。使用中文，优先桌面工作台，窄屏侧栏收起。复用颜色、字体、控件和面板规则，Accord 使用自己的身份、文案和业务状态。

保留 FastAPI / SQLite 的后端方向，基于已读 MVP 数据与行为实现受控接口；原有匿名全量快照、未鉴权状态修改和模型直接写状态不能成为新前端的依赖。模型未配置时明确呈现资料检索演示，不伪装成真实模型代答。
