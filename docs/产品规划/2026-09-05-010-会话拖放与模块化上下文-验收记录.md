# 会话拖放、协作工作区与同人聊天验收

> 2026-09-05。供 JC 与 Accord 队友检查本轮可用范围。依据当前源码、隔离账号的真实模型调用、浏览器操作和服务检查；测试数据与团队实际工作区分开保存。

## 已交付的行为

本轮将 [007 独立探索与集中收束](2026-09-05-007-独立探索与集中收束工作流-实施计划.md)、[010 文件夹与上下文](2026-09-05-010-会话拖放与模块化上下文-设计文档.md) 和 JC 后续同事反馈接到同一应用中。工作台用于自己的工作、文件夹、资料、课题和待办；聊天按同事保留一个入口。点击已有同事不会不断新建对话，历史事项在同一窗口中呈现。新的事项保留自己的上下文和访问范围。

Agent 代答、请本人接入、真人回复、本人确认、任务完成都在原对话中进行。原输入框就地承接转交说明与确认结论，页面用文字、状态点和消息样式区分 Agent、等待本人、真人接续。任务卡可由负责人设置高、普通、低优先级及完成状态；模型回答不会自动接受任务。

| 用户操作 | 实际结果 |
| --- | --- |
| 创建文件夹，拖入个人工作聊天；或使用“移动到”菜单 | 保留聊天 ID 和历史，只改变个人位置；可以撤销 |
| 给文件夹配置资料，拖入另一聊天的资料区 | 保存持续引用，来源改变后用于下一次请求；也有选择器和移除入口 |
| 增补或移除当前资料 | 保存本会话的附加项与排除项，刷新保留；不删除源资料 |
| 新建正文、导入 Markdown / 文本、组合资料 | 保存私有或明确发布的团队资料，更新产生新版本；集合保留引用版本 |
| 模型回答相关问题 | 通过真实只读工具查阅获准资料，保留来源版本、步骤、停止、失败和用量 |
| 发起课题、各自探索和提交 | 固定共同简报，私人过程分别保留；提交是不可变版本，不立即公开 |
| 主持人统一公开、比较并确认决策 | 同一事务公开本轮提交，比较使用干净的会话；决策交给本人后仍需明确承接 |
| 将个人工作交给同事 | 页面内预览接收者与待发正文，明确发送后形成协作；不把整个私人历史自动复制出去 |

## 工作状态与权限

落实 [008 状态与权限设计](2026-09-05-008-团队工作状态与可见权限-设计文档.md) 的首批范围。设置中有两个本人控制的选项：“我在 Accord 聊天或工作的状态”和“我正在处理的事项标题”，默认关闭。开启后只收集 Accord 页面活动，不读取屏幕、其他应用、键盘内容或草稿正文。活动通过页面心跳更新，75 秒没有有效信号即不再当作当前活动；本人设置的“专注中”优先保留。

开启事项标题不等于公开聊天。同事与第三人的私人对话标题，以及未获准的独立探索内容仍被过滤。双方已经共享的记录可以在同人聊天中阅读；待办进度与优先级只返回查看者本来有权访问的任务。Agent 运行和本人页面活动分别表示，不把 Agent 正在生成解释成本人在工作。

新增 colleague_status 只读工具：即使资料区为空，也能查询当前对话对象主动共享的状态和双方可见待办。工具不能指定其他调用身份、遍历私人聊天或读取日历；每次调用及输出前复核有效权限。会议状态尚未接入，不能据此显示“开会中”。

## 实际验证

| 验证 | 结果与口径 |
| --- | --- |
| 后端自动化测试 | 42 项通过，包含幂等、并发公开、私有会话隔离、固定资料版本、引用撤权、同人记录过滤、状态开关和任务权限 |
| 真实资料调用 | 两个隔离账号分别探索，再创建干净的比较会话；3 次生成完成，合计 6 次真实工具读取，模型回报 6,931 tokens |
| 真实状态调用 | 资料为空的同事 Agent 通道实际调用 colleague_status，随后在原窗口完成转接、回复、确认、优先级和完成操作 |
| 浏览器工作区操作 | 拖动移动、撤销、菜单移动、持续文件夹引用和刷新保留通过；参与者之外的账号读取私人聊天返回 404 |
| 浏览器课题操作 | 两人分别提交；另一人不能提前看到方案；主持人统一公开后比较并确认决策 |
| 权限和页面尺寸 | 本人开关经过服务端保存确认；聊天和课题在 1440、768、390 宽度与明暗主题下检查，无页面级横向溢出、无脚本错误 |
| 编译与 UI 规则 | TypeScript 与构建通过，公共组件、图标与语义色检查通过；主脚本约 522 KB，仍有 Vite 分块体积提示 |

三次资料生成的实测耗时约 4.0、6.1、8.1 秒。这是隔离验收账号使用轻量思考的单次记录，不代表最高思考档或多人使用时的性能承诺。当前实际模型配置继续沿用项目的 DeepSeek 配置；没有把密钥放入前端或文档。

浏览器测试曾因同名联系人定位、测试聊天已在文件夹中，以及权限保存尚未返回就读取勾选状态而中断；已修正定位、用例初始位置和等待条件后，分别续跑受影响步骤。截图在设置关闭动画结束后重新采集；没有将中断截图作为通过证据。

本地证据位于 screenshots/2026-09-05-协作迭代；受限的脚本和结果在 .local/iteration-1。均未上传运行日志、数据库或真实成员内容。服务按现有 launchd 方式载入，更新前检查运行队列并备份实际数据库；隔离验收未向实际团队空间添加测试成员和方案。

## 仍未完成的范围

- 飞书或其他日历的会议状态、自动预约、会议内容读取仍需独立连接和授权；目前不推断正在开会。
- 共享整段私人历史、文件夹持续公开、按指定群组授权、撤回已经送达的正文，以及完整权限申请流程仍未实现；现有分享以明确选取的正文和获准引用为准。
- 任务已有优先级与完成状态，尚无按执行步骤自动计算的百分比、依赖与受阻状态；当前进度展示已完成数和可见待办数。
- 资料导入限 Markdown / 文本；PDF、Office、任意本地目录、飞书实时检索与正文编辑工具不属于本批。
- 文件夹尚无嵌套、手动排序、跨人移动；完整搜索、通知中心、已读、群聊、独立的协作事项关闭与 Agent 再接管流程仍需后续补齐。
- 仍为单工作空间、单 API 进程的本地服务与已配置的局域网预览；没有因此完成云部署、多 Runner、多 Agent 委托或全面像素还原。

下一轮优先用两台真实设备验证本人接手与状态共享，再接入团队实际使用的日历或会议来源。继续以真实可读数据和明确受众补能力，不增加占位状态或自动公开私人过程。
