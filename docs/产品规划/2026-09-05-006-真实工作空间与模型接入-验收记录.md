## 已实现内容

- 真实邮箱标识与密码账号：PBKDF2 哈希、HttpOnly Cookie、会话过期、退出撤销、登录次数限制、创建者签发一次性邀请码。邮箱验证、找回密码、成员停用及角色管理未实现。
- 实际工作空间使用 `.local/workspace`；此前数据库仍保留在原目录。验证账户仅位于独立 `.local/validation` 或临时测试目录。
- 消息提交先落库，再进入 SQLite 后台队列。调用前检查幂等键和并发限制；模型不持有业务写权限。
- 实际模型为 `qwen3.7-flash`。没有共享资料时也可处理一般问题；涉及团队事实时提示必须有上下文依据。历史只取当前会话，资料只取明确共享的内容。
- 生成状态持久化，支持停止、失败重试、部分内容保留和真实用量。重启后不自动重放可能已经付费的中断调用。
- 定时转交由服务端后台执行，不依赖用户读取页面。确认承担任务和完成任务仍是不同的人类动作。
- 40px 顶栏、窗口内导航、输入区结构、实际上下文面板、亮暗主题、按账号/会话保留标签页草稿、Markdown 表格/列表/代码、复制与阅读位置保护。

2. 首轮提供一个名称，次轮只问此前约定的名称；模型正确引用历史。请求与回答不是硬编码内容。

## 验收中修复的问题

- 开发代理的页面来源与 API Host 不一致导致登录被拒绝：明确代理 Host 行为和站点来源。
- 两个开发服务共用依赖缓存导致 React 重复实例和空白页：按服务隔离 Vite 缓存，并补充页面错误恢复入口。
- 新会话草稿标识随刷新改变：改为稳定存储标识，新建动作负责清空。
- 已保存消息遇到后续刷新失败被当作发送失败：区分提交回执与页面同步，避免重复发送。
- 依赖审计发现 Vite 6.4.2 公告：升级兼容补丁版本 6.4.3，重新构建。

## 当前使用边界

这是已经连通真实模型和数据存储的本机版本，不是完整团队上线验收。服务端单进程、SQLite、本机监听；浏览器每秒拉取持久状态，上游模型采用流式接口。尚缺 HTTPS 部署、备份恢复演练、容量监测、通知推送、飞书 SSO、账号恢复、资料版本与权限撤销流程。

“Agent”目前能对话和整理，不能调用文件工具、浏览器、终端或外部业务系统。多 Agent 的委托、沙箱、工具批准与执行产物仍在架构设计阶段。模型回复不会自动确认、分派或完成任务。

未做 Tutti 同尺寸逐像素比对，不报告还原率。窗口调宽、工具侧栏、文件联动、多窗口与工具执行状态是下一批明确缺口，而非已完成能力。
