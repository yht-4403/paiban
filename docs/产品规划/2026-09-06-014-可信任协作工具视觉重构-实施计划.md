## 4. Design Direction（设计方向）

- Surface type（页面类型）: 高频使用的协作产品工作台。
- User mood and physical scene（用户情绪和使用场景）: 小团队成员在明亮办公环境或夜间长时间工作，需要迅速辨认责任、资料与下一步，不能被视觉噪声打断。
- Color strategy（色彩策略）: Restrained；亮色默认，冷蓝紫主色不超过约 10% 视觉重量，黄 / 珊瑚 / 紫只做身份与状态火花，暗色单独设计三层表面。
- Typography strategy（字体排版策略）: 产品正文保持 Lexend + 系统中文回退；Georgia 只保留 Accord 字标；标题提高一级字号和字重，元数据继续降噪。
- Layout strategy（布局策略）: 导航面、内容面、上下文面三层明确；Composer 是主操作面；列表优先用间距和分隔线，不新增卡片海。
- Motion strategy（动效策略）: 150–220ms 状态过渡，无页面编舞，保留 reduced-motion 兜底。
- Proof / trust strategy（证明和信任策略）: 颜色从不代替 Agent / 真人、资料范围、任务状态、错误与接收者文字。
- AI-slop risks to avoid（要避免的 AI 味）: 霓虹渐变、玻璃拟态、彩色侧条、过度圆角、同尺寸卡片网格、装饰性动效。
