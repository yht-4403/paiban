# Tutti 工作台接入验收记录

> 2026-09-05。本轮交付是可运行的本地协作主流程，前端直接接入 Tutti UI System。成员、资料和演示请求均为合成数据。

## 已交付

- React 19 / TypeScript / Vite 6 / Tailwind 4 前端，直接使用 `@tutti-os/ui-system@0.0.427` 的公共控件、图标、语义颜色和字体。
- 亮暗主题、组件样板、个人工作台、找同事、待我拍板、我的待办、共享成果与项目上下文。
- FastAPI / SQLite 本地服务，会话身份、可见范围校验、人工转交、指定时间送达、确认任务和幂等操作。
- 启动脚本、行为测试、UI 检查、[长期 UI 规范](../../harness/规范/004-AccordUIUX设计规范.md)和[来源记录](../../THIRD_PARTY_NOTICES.md)。没有修改 ChengziCV 或 Tutti 参考源码。

## 运行入口

[Accord 工作台](http://127.0.0.1:5186)与[组件样板](http://127.0.0.1:5186/#gallery)仅 JC 本机可访问。API 监听 `127.0.0.1:8786`，数据在 `.local/accord-data`。队友需获取仓库并按 [README](../../README.md)安装运行。

```bash
npm ci --ignore-scripts
python3 -m venv .venv
.venv/bin/python -m pip install -r apps/api/requirements.txt
python3 tools/dev-services.py start
```

macOS 用户域服务为 `com.accord.web`、`com.accord.api`；支持 start / stop / status。重启时等待旧服务卸载再加载，避免 launchd 的卸载竞争。旧 MVP 8765 和 Tutti 参考实例继续独立运行。

## 浏览器实测

| 检查 | 结果与证据 |
| --- | --- |
| A 问 B 的 Agent | 林川询问苏禾的工作台 UI / 联调资料，页面返回共享文档摘录和可点击来源；明确标为资料检索 |
| 转交前后可见性 | 苏禾独立标签页在转交前无该请求；林川明确点击找本人后，苏禾待我拍板出现请求 |
| 人工判断与任务 | 苏禾回复、填写任务名称和结论并确认；双方出现同一条“完成 Accord 工作台联调验收”待办，只有苏禾可完成 |
| 刷新与服务恢复 | 新标签页可读取已存任务；刷新后保留身份、资料和记录。主动停 API 后出现连接中断及重试入口，重启服务后恢复 |
| 视觉与组件 | 桌面亮暗主题可用；实测默认 Button 为 32px 高、6px 圆角、13px 字号；输入、Checkbox、按钮反馈正常 |
| 键盘与弹窗 | Escape 关闭后焦点返回“打开弹窗”；关闭入口已本地化为中文；发送区处理中文输入法合成状态 |
| 响应式 | 浏览器原生视口覆盖未生效，因此使用独立 iframe 的真实 390 / 768 / 1440px 视口检查，DOM scrollWidth 均等于视口宽度；390px 导航与任务操作可用 |

修复了验收发现的头像被宽泛 CSS 选择器覆盖、转交说明未展示、接收方标题显示自己、退出样板后 URL hash 未清除，以及窄屏保留无效上下文开关的问题。

响应式检查不等同于手机真机、软键盘、触控和浏览器兼容性认证。截图中的响应式预览外框属于本地验收工具，不属于产品页面。

## 自动检查

```bash
npm run typecheck
npm run build
npm run check:ui
PYTHONPATH=apps/api .venv/bin/python -m unittest discover -s apps/api/tests -v
```

上述检查已通过。后端 8 项测试覆盖：匿名与旧路由不可用；A/B/C 可见范围；模型只得到共享资料且不能写任务；确认人、事务与并发幂等；闲聊不能误完成任务；指定送达时间时区与可见范围；消息重试与操作冲突；关闭演示登录入口。测试使用临时数据库，不污染演示数据。

构建产物约 412KB JS（gzip 128KB）和 133KB CSS（gzip 22KB）。健康接口经 API 直连和 Vite 代理均返回正常。正常交互过程中未观察到控制台警告；断连演练产生预期网络错误。

## 与 Tutti 的关系

已采用其公共组件和视觉语言，页面结构围绕 Accord 的“先查资料、明确找人、本人确认”组织。源码参考 commit 为 `404a084f7780c475212f80d6563964c4bd7d8324`，实际 npm 包为 0.0.427，两者没有宣称逐文件相同。UI 包的 LICENSE / NOTICE 和 Lexend 许可随 web 公共资源保存。

本轮没有实现 Tutti 的桌面壳、终端、文件执行、VM、多设备共享运行时或其完整功能矩阵。

## 限制与下一步

- 真实模型尚未配置；当前为共享资料检索。即使配置接口也需另行验收供应商、失败恢复与回答质量。
- 演示身份可以主动切换，专用于本机合成数据，不是生产用户认证。服务仅监听回环地址，未开放双机。
- 状态每 3 秒轮询；不是 WebSocket 推送或外部飞书通知。指定时间请求依赖服务运行和后续读取触发送达，不保证服务停止期间准点通知。
- 当前仅以全部成员已明确共享的文档作为可转述材料，没有实现逐资源授权、私人记忆问答、附件上传或权限撤回。
- 任务只由接收者本人确认并承担；多人会议、第三方派工、改约 / 撤回、真实飞书任务写入仍待实现。
- 旧原型问题仍适用于旧 `.local/` 副本；新接口绕开了相关旧路由与模型写操作，本记录不能解释为对旧程序的全面修复。

下一步优先接入一个真实模型、用同一条主流程完成队友联调和比赛实录；范围继续以 [004 实施计划](2026-09-05-004-Tutti工作台接入-实施计划.md)为准。
