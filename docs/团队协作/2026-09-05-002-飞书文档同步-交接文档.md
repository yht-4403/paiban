## 发布边界

同步只发布整理后的项目文档。`.env`、私人会话、数据库、运行日志和原始云盘缓存不在范围内。源码和所有本地截图不会随 docs 自动上传；需要作为证据的截图逐张检查后处理。

正文中的本地源码路径、诊断结果路径和 localhost 服务仅供 JC 本机定位，队友不能通过它们直接打开本地服务。文档之间的链接在飞书副本中替换为在线链接。

本约定没有自动发送群消息、修改公开权限，也未部署文件监听器或定时任务；它在后续 Agent 任务的交付流程中执行。长期执行规则已写入仓库 `AGENTS.md` 和 `harness/规范/003-飞书文档同步规范.md`。
