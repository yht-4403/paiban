## 四、后续如何续读

已下载的原始 Markdown 与部分在线文档 JSON 在本地 `.local/sources/feishu/`。目录由 Git 忽略；其中可能含内部材料，不作为公开资料分发。获取的在线文档 JSON 保留完整响应，而不是只留脱离引用元数据的正文。

续读时使用来源 URL，并遵循对应 `lark-*` Skill。以下为已使用的只读命令形式：

```bash
lark-cli drive +search --query 'AlxOrigin Team' --doc-types folder --only-title --as user
lark-cli schema drive.files.list
lark-cli drive files list --params '{"folder_token":"XHl4fbIS2lPF61dHGkecbtz7njg","page_size":200}' --as user
lark-cli docs +fetch --doc OauGdFaZRoh0ENxtpCfcGxRfnD1 --doc-format markdown --as user
```

目录列表按返回的 `has_more` 和 `next_page_token` 手动处理分页。本次读取的目录页均返回 `has_more=false`，但没有对 Demo 代码和数据目录做完整递归，不能称作全量云盘备份。
