# DeepSeek 模型与思考配置

> 2026-09-05（北京时间）。当前 Accord 已从千问切换至 DeepSeek V4 Pro；最高思考、个人设置、实际模型调用和运行服务均已验证。

## 使用方式

默认模型是 `deepseek-v4-pro`，思考模式开启，强度为 `max`。右上角「工作空间设置 → 你的思考强度」可以选择：

| 页面选项 | API 参数 | 适用方式 |
| --- | --- | --- |
| 轻量 | low | 简短问题、希望更快取得回答 |
| 深入 | high | 一般分析与资料整理 |
| 最高（默认） | max | 复杂分析，通常等待更久、用量更多 |

每位成员的偏好独立保存在服务端，重新打开浏览器仍有效。队友未设置时使用最高档。修改影响下一次发起或重试的回答，排队和生成中的回答保留发起时的强度。重新生成采用当前设置，便于在达到思考上限后降低强度再试。

会话输入区展示当前模型和思考档位。运行过程区分连接、思考、查阅资料和输出回答，可继续使用停止与重新生成。思考强度控制模型投入程度，不承诺每个简单问题都产生大量思考 token。

## 服务端配置

根目录 `.env` 由 API 启动脚本读取，权限为 0600；实际 Key 不进入前端、launchd 参数、日志、Git 或本文。使用 JC 本次提供的 DeepSeek 凭据，未修改 ChengziCV 配置。可提交示例保存在 `.env.example`，Key 留空。

```dotenv
ACCORD_LLM_PROVIDER=deepseek
ACCORD_LLM_BASE_URL=https://api.deepseek.com
ACCORD_LLM_MODEL=deepseek-v4-pro
ACCORD_LLM_REASONING_EFFORT=max
ACCORD_LLM_MAX_TOKENS=65536
ACCORD_LLM_TIMEOUT_SECONDS=900
ACCORD_LLM_DAILY_LIMIT=200
```

请求使用 `thinking: {type: "enabled"}` 与 `reasoning_effort`。这里的 `max` 是官方最高思考强度；输出上限另设为每次上游请求 65,536 tokens，并非无限生成或官方最大输出长度。一次回答最多沿用现有七轮模型请求限制，工具调用会产生后续请求；用量累加实际回报。工作空间仍为两条后台生成并发、每人同时一条，每人每日最多发起 200 次生成记录。

整次回答默认运行时限 900 秒，网络连接超时 10 秒、读流静默超时 60 秒。停止在收到流事件或网络超时时检查；不会声称停止按钮必然立即终止供应商已开始计费的计算。余额不足、授权失败、限流、网络中断和思考预算耗尽均保留明确错误，不自动重发收费请求。

## 思考与资料工具兼容

DeepSeek 的推理内容位于流事件 `reasoning_content`，与用户可见回答 `content` 分开。调用资料工具后，按供应商要求将对应思考内容连同工具结果传回，避免后续请求缺少字段而失败。

运行期间的思考内容只用于模型续接；完成后保存在服务端运行记录，以支持下一轮工具会话。普通消息 API 和页面不返回这段内容。历史引用仍经过现有权限、会话和资料版本校验，模型不能借此读取其他人的私有会话。迁移前的回答没有思考记录，保留为空，不补造。

`accord_model_preferences` 保存账号偏好；`accord_runs` 增加思考强度快照与内部思考字段。迁移增列，保留已有账号、会话、任务和资料。网页仅获取可用档位、当前个人档位、运行阶段与实际用量。
