Quick Tunnel 无需购买域名，地址随机生成，进程重启可能更换；电脑必须保持开机联网、不休眠。它限制 200 个并发中的请求，且不支持 SSE。当前网页采用轮询，上游模型 SSE 发生在后端与供应商之间，所以不经过该隧道。依据：[Cloudflare 官方 Quick Tunnel 文档](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/)。跨运营商与移动网络的实际连通性仍需分别验证。

## 访问与数据边界

- 工作空间必须先在本机完成创建。外网入口始终禁止首次管理员创建接口。
- 队友使用自己的账号；新增成员仍需要创建者生成的一次性邀请码。业务 API 保留原有认证与成员可见范围。
- HMR 会向浏览器提供前端源码和依赖模块；禁止访问后端源码、根配置、仓库文档、密钥、数据库和私有目录，检查编码路径、目录穿越和符号链接。
- Vite 只接收当前预览域名；不设置允许所有域名。外网会话 Cookie 加 Secure，保留 HttpOnly 和 SameSite；跨站写请求仍由后端拒绝。域名限制依据：[Vite 官方服务端配置](https://vite.dev/config/server-options)。
- 真实模型调用沿用现有服务端凭据与额度，密钥不发给浏览器。当前有每人每日请求次数限制，但没有独立工作空间总费用上限；受邀成员的真实调用会消耗当前上游账号额度。
- Cloudflare 是外网请求的 HTTPS 中转服务。开放的是当前实际工作空间，不会自动复制成一份独立数据集，也不会创建预置人物或内容。

## 运行与关闭

macOS ARM64 的官方 cloudflared 2026.8.3 已下载到 `.local/bin`，SHA-256 与官方 GitHub release 的资产摘要一致。安装器固定版本并拒绝覆盖已有程序；其他平台需另行适配。

```bash
# 首次安装；本机已安装时无需再执行
python3 tools/install-cloudflared.py
# 获得本次真实工作空间外网开放授权后执行
python3 tools/preview-services.py start
python3 tools/preview-services.py status
# 关闭临时共享，不停止本地开发服务
python3 tools/preview-services.py stop
```

`com.accord.preview` 由当前用户 launchd 托管，管理独立前端和隧道子进程。状态文件为 `.local/preview/status.json`，日志为 `/tmp/accord-preview.log`。隧道重连后用 status 查询当前地址，不在长期文档中固化随机 URL。公网隧道生命周期尚待实际验收。

## 后续正式部署

建议将前端构建产物、API 和后台生成任务封装成可版本化的镜像，部署到 Sealos 或同类容器平台，配置固定访问入口、HTTPS、服务端凭据和数据备份。Sealos 官方提供应用部署、环境变量、持久存储及版本更新入口，见 [App Deploy](https://sealos.io/docs/guides/app-deploy/)。本轮未创建云资源或产生云端部署费用。

当前 API 使用单进程调度与 SQLite。首轮上云保持单实例，数据目录挂载持久卷，并验证重启、备份和恢复；不要直接开启多副本。需要多实例时，先改为共享数据库与独立任务队列。模型凭据与预算应独立管理。

临时开发访问和正式用户访问采用不同发布方式：前者随保存而变化，后者通过已检查的版本发布。若队友需要电脑关机后仍可访问，可以提前部署一个云端测试环境，再单独设置正式环境。

## 2026-09-05 局域网共享记录

JC 已明确将访问范围改为同一局域网。当前共享地址为 http://192.168.18.225:5188/，同一 Wi-Fi 下的成员使用各自账号登录，新成员通过一次性邀请码加入。公网 Cloudflare 进程已停止，不再通过原来的临时公网链接访问。

启动命令为 `python3 tools/preview-services.py start --lan`，查询地址为 `python3 tools/preview-services.py status`，关闭为 `python3 tools/preview-services.py stop`。默认 start 同样采用局域网模式，不需要注册隧道账号或安装新的中转软件。换 Wi-Fi 或局域网 IP 改变后重新 start，再以 status 返回地址为准。

前端仅监听当前 Wi-Fi / 以太网的私有 IPv4 地址，API 继续只监听 127.0.0.1:8786；根配置、私密文件与首次管理员创建入口保持拦截。LAN 转发使用实际连接 IP，忽略外部伪造的 Cloudflare 请求头。局域网 HTTP 会话保留 HttpOnly 与 SameSite。

浏览器在普通 HTTP 下可能不提供 randomUUID 和 Clipboard API。本轮增加基于 getRandomValues 的请求编号，以及用户点击触发的复制兼容处理，避免发送请求或复制时出现异常；复制失败仍明确提示，不显示虚假成功。
