# Accord 90 秒产品讲稿

负责人：堡天  
状态：已完成  
用途：现场产品介绍

我们正在做 Accord，一套给 AI 原生小团队使用的协作工具。

现在团队里每个人都在和自己的 AI 工作，但成果散落在各自的对话和文件中。你想问同事一个已经回答过的问题，仍然要打断他；开会前不知道谁真的需要参加；会后派出的任务完成了，也常常要等下一次会议才被看见。

Accord 给每个人一个受权限约束的 Agent 和工作池。第一步，我直接询问堡天的 Agent。它只读取堡天明确共享的成品，回答后展示来源；如果答案已经够用，堡天本人不会被打断。

第二步，发起会议前，值班 Agent 分别收集成员进展，把已完成、待确认和未知的信息整理出来，只推荐真正需要拍板的人参会。

第三步，会后任务根据成员职责和已有成果推荐负责人，最后仍由人选择。负责人完成工作、发布成果并勾选待办后，Agent 会先查证，再总结完成结果。

整个过程中，私人工作台默认不公开，Agent 不知道就说不知道。我们没有替代人做决定，只是把重复查资料、会前收集和会后追踪交给 Agent，让人的注意力留给真正需要判断的事情。
