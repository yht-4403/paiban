# Accord 工作台 1440 宽度复核结论

负责人：舒奥  
复核宽度：1440 × 900  
状态：已完成

## 检查范围

- 左侧工作台与找同事入口
- 中间聊天正文、来源展开和输入框
- 右侧待办、工作池、文件搜索与预览
- 开会和任务分配的表单及结果页

## 结果

1. 聊天正文保持为页面第一阅读层级。常规段落行宽可读，长回答没有被右侧栏压成窄列。
2. 待办与工作池同时展开时，标题和主要动作仍完整显示；次要说明已减少，没有遮挡复选框或上传入口。
3. “已查阅”和资料来源默认折叠，展开后在正文内向下延伸，没有覆盖底部输入框，也没有造成横向滚动。
4. 工作池的“拖入成品”、搜索、文件列表和预览顺序清楚。文件名过长时截断，不挤压引用操作。
5. 决策会和任务分配表单在 1440 宽度下无需横向滚动，成员复选框、主按钮和返回入口可以直接找到。

## 本轮处理

- 保留高频动作和内容，减少常驻解释文字。
- 待办继续放在右侧，不恢复独立大入口。
- 工作池只显示团队成品，不把个人过程附件混入列表。
- Agent 状态采用具体阶段文字，不增加倒计时弹窗。

## 仍需关注

- 三个窗口并排时，每个窗口会进入窄屏布局，现场应以一个主窗口投屏，另外两个窗口只在切账号和查看待办时使用。
- 超长中文文件名仍需要观察真实资料量增加后的截断效果。
- 模型回答长度由内容决定；现场不应通过固定高度裁掉正文或来源。
