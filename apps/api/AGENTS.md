# Python 后端开发入口

先读本目录 [README.md](README.md)，继承仓库根规范。

- 新功能优先落在 `accord_api/modules/<业务>`；不要重新向包根目录添加零散业务文件。
- HTTP 请求与 Cookie 只进入接口边界。业务用例接收显式身份和结构化参数，抛 `DomainError`；不得依赖 FastAPI 的 `Depends` 或 `Request`。
- `platform` 不导入业务模块；provider 不读取数据库。新增工具同时维护参数清单、权限检查、执行预算、版本引用和审计记录。
- 资料目录为空仅代表本次可读资料不足；不能宣称读取了用户全部记录。私聊、群聊、课题分别保留当前权限与历史边界。
- 文件移动不得改变默认数据目录。迁移在旧库副本上校验；不在真实成员数据上跑写入测试，不自动重放付费模型调用。
- 测试使用隔离数据目录。新增接口或变更既有接口须说明契约变化，不能为了让契约快照通过而盲目更新快照。
- 默认单进程 SQLite；引入外部队列、ORM 或多副本须有实际需求与对应迁移、运行验证。
